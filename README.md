# Sales & Revenue Analytics Using Python, SQL and Excel

## Project Overview

This project analyzes retail sales transaction data to identify revenue trends, product performance, geographic sales patterns, customer purchasing behavior, and key business insights.

The analysis combines **Python, SQL, and Excel** to demonstrate an end-to-end data analytics workflow, from data cleaning and feature engineering to business analysis, SQL validation, and dashboard creation.

---

## Business Objective

The objective of this project is to analyze sales transaction data and answer key business questions such as:

- How much revenue was generated?
- Which products generate the most revenue?
- Which products have the highest sales volume?
- Which cities contribute the most revenue?
- Which months recorded the highest revenue?
- What is the peak sales hour?
- What products are frequently purchased together?
- What insights can support inventory planning, promotions, and cross-selling?

---

## Dataset

The dataset contains retail sales transaction records with information about:

- Order ID
- Product
- Quantity Ordered
- Price Each
- Order Date
- Purchase Address

### Dataset Size

- Original records: **30,394**
- Final cleaned records: **30,206**
- Original columns: **6**
- Final analytical columns: **11**

The dataset contains sales transactions from 2019, with records available for April, May, August, and September.
